# Gemini instructions for ByteMyWave

Do not analyze this repository from the default `main` branch alone.

Before answering any project-wide question, especially about Kimi K3, Transit GPU, DDR3, 304 channels, 38 tiles, ~100 tokens/s, throughput, benchmarks or current implementation status:

1. Read `AGENTS.md`.
2. Read `docs/REPOSITORY-MAP.md`.
3. Inspect open PRs and non-default branches.
4. For Kimi K3, inspect PR #9, PR #10 and PR #11 and their branches.
5. Distinguish measured benchmark results, simulations/rooflines, weight-path tok/s equivalent and end-to-end model tok/s.

If you cannot access branches/PRs, say that your inspection is limited to `main`; do not conclude that deeper information is absent.

Canonical instructions: `AGENTS.md`.
