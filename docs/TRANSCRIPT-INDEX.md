## Preservation rule

Do not silently rewrite older transcript segments to match later conclusions.

If an earlier assistant statement is later shown to be wrong, keep it in the transcript and correct the technical claim in project documentation/ADRs.

Tool-call internals, hidden prompts and connector payloads are not part of the conversation transcript. User-visible user/assistant discussion and resulting project decisions are the material being preserved.
